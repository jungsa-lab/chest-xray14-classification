# `src/` 디렉터리 구조

`src/`는 ChestX-ray14 프로젝트의 데이터 전처리, 분석, 모델 학습 및 평가에 사용되는 소스 코드를 관리하는 디렉터리입니다.

각 폴더는 기능에 따라 구분되어 있으며, 관련 작업은 해당 폴더에서 관리합니다.

## 1. 디렉터리 구성

```text
src/
├── analysis/        # 데이터 분석 및 시각화
├── data/            # 모델 입력 데이터 처리
├── dicom/           # DICOM 파일 관련 실습
├── evaluation/      # 모델 성능 평가
├── preprocessing/   # 데이터 전처리 및 분할
├── training/        # 모델 구성 및 학습
├── constants.py     # 공통 상수
└── paths.py         # 공통 경로
```

| 디렉터리 | 주요 역할 |
|---|---|
| `analysis/` | 데이터의 특징을 분석하거나 결과를 그래프로 표현하는 코드 |
| `data/` | 이미지와 정답 데이터를 모델에 입력할 수 있는 형태로 변환하는 코드 |
| `dicom/` | DICOM 파일을 읽고, 확인하고, 처리하는 실습 코드 |
| `evaluation/` | 모델의 예측 결과를 바탕으로 성능을 계산하는 코드 |
| `preprocessing/` | 원본 데이터를 검사하고 학습에 사용할 데이터를 준비하는 코드 |
| `training/` | 딥러닝 모델을 정의하고 학습시키는 코드 |

## 2. 폴더별 파일 구성

### `analysis/` — 데이터 분석 및 시각화

전처리된 데이터를 분석하고, 이미지나 통계 결과를 확인하는 데 사용합니다.

| 파일 | 역할 |
|---|---|
| `summarize_labels.py` | 질환별 데이터 수와 Fold별 라벨 분포 확인 |
| `plot_cooccurrence.py` | 여러 질환이 함께 나타나는 빈도를 분석하고 시각화 |
| `review_image_quality.py` | 밝기 등을 기준으로 이미지 품질 검토 |
| `compare_clahe.py` | CLAHE 적용 전후 이미지 비교 |
| `compare_clahe_bbox.py` | 질환 영역(BBox)을 중심으로 CLAHE 적용 결과 비교 |
| `measure_clahe_bbox.py` | 질환 영역(BBox)의 대비·CNR 등으로 CLAHE 효과를 정량 비교 |
| `summarize_prevalence.py` | 전체 데이터의 이미지·환자 기준 질환 유병률 집계 |
| `plot_conditional_cooccurrence.py` | 한 질환이 있을 때 다른 질환이 함께 나타나는 비율 시각화 |

데이터 통계나 시각화 자료를 추가할 때 사용하는 폴더입니다.

### `data/` — 모델 입력 데이터 처리

이미지와 라벨을 실제 모델 학습에 사용할 수 있도록 준비합니다.

| 파일 | 역할 |
|---|---|
| `chest_xray_dataset.py` | 이미지와 질환 라벨을 불러오는 Dataset 및 학습·검증 Fold 선택 |
| `image_transforms.py` | 이미지 크기 변경, CLAHE 적용, 텐서 변환 및 정규화 |

이미지 입력 방식이나 Dataset의 동작을 수정할 때 사용하는 폴더입니다.

### `dicom/` — DICOM 관련 실습

의료영상 파일 형식인 DICOM을 다루는 코드입니다.

| 파일 | 역할 |
|---|---|
| `inspect_dicom.py` | DICOM 파일의 구조와 메타데이터 확인 |
| `view_dicom_sample.py` | DICOM 영상 불러오기 및 시각화 |
| `deidentify_dicom_sample.py` | DICOM 메타데이터 제거 실습 |

현재는 `pydicom`의 공개 CT 샘플을 사용하며, ChestX-ray14의 PNG 기반 모델 학습 과정과는 별도로 구성되어 있습니다.

### `evaluation/` — 모델 성능 평가

모델의 예측 결과를 평가하는 기능을 관리합니다.

| 파일 | 역할 |
|---|---|
| `metrics.py` | 질환별 AUROC, AUPRC(AP), ECE 및 평균 성능 지표 계산 |

성능 지표를 추가하거나 평가 방법을 수정할 때 사용하는 폴더입니다.

### `preprocessing/` — 데이터 전처리 및 분할

원본 데이터로부터 학습에 필요한 메타데이터를 생성하는 작업을 담당합니다.

| 파일 | 역할 |
|---|---|
| `prepare_training_data.py` | 메타데이터 정리, 이미지 검사, 환자 기준 Train/Test 분할 및 5-Fold 구성 |

데이터 분할 기준이나 전처리 과정 자체를 변경할 때 사용하는 폴더입니다.

### `training/` — 모델 구성 및 학습

모델 구조, 손실 함수, 학습 과정에 필요한 코드를 관리합니다.

| 파일 | 역할 |
|---|---|
| `model.py` | DenseNet-121 기반 14개 질환 분류 모델 생성 |
| `losses.py` | Focal Loss 구현 |
| `weights.py` | 질환별 데이터 불균형을 고려한 가중치 계산 |
| `engine.py` | 모델의 1 Epoch 학습 및 검증 처리 |

모델 구조를 변경하거나 학습 방식을 추가할 때 사용하는 폴더입니다.

## 3. 공통 파일

`src/` 바로 아래에 있는 파일은 여러 폴더에서 공통으로 사용합니다.

| 파일 | 역할 |
|---|---|
| `constants.py` | 14개 질환의 이름과 출력 순서를 정의 |
| `paths.py` | 데이터 및 결과 파일의 공통 경로를 정의 |

여러 모듈에서 사용하는 값이나 경로는 가능한 한 공통 파일을 기준으로 관리합니다.

## 4. 작업별 위치

| 작업 | 관련 경로 |
|---|---|
| 데이터 분할 또는 Fold 생성 방식 변경 | `preprocessing/` |
| 이미지 크기나 정규화 방식 변경 | `data/` |
| 데이터 분포 분석 및 그래프 생성 | `analysis/` |
| 모델 구조 변경 및 새로운 모델 추가 | `training/` |
| 손실 함수 또는 학습 방식 변경 | `training/` |
| 새로운 성능 평가 지표 추가 | `evaluation/` |
| DICOM 파일 관련 기능 추가 | `dicom/` |
| 질환 목록 또는 공통 경로 수정 | `constants.py`, `paths.py` |

## 5. 참고 사항

- 원본 데이터와 전처리 결과는 `src/`가 아닌 프로젝트 루트의 `data/`에서 관리합니다.
- 분석 결과와 시각화 자료는 `reports/`에서 관리합니다.
- 실행 환경 및 데이터 입력 확인용 스크립트는 `scripts/checks/`에 있습니다.
- 단위 테스트 코드는 프로젝트 루트의 `tests/`에서 관리합니다.
- 현재 `training/`에는 모델 정의와 기본 학습·검증 기능이 구현되어 있으며, 전체 학습 실행 및 실험 자동화는 후속 작업에 포함됩니다.
