# Subgroup Analysis (Test)

- 데이터: Test 16,724장, Ensemble (보정 확률, AUROC는 보정과 무관)
- 질환별 AUROC는 그룹 안에 양성·음성이 각각 10개 이상일 때만 계산. Mean AUROC는 같은 속성의 모든 그룹에서 계산 가능한 질환만 평균
- 95% CI: 환자 단위 Bootstrap 200회
- 성능 차이 = (최고 − 최저) / 최고. 10% 이상이면 원인 분석 대상

## 원인 분석

> 분석 본문: [`discussion.md`](discussion.md) 1절 (직접 작성, 다시 실행해도 덮어쓰지 않음). 확인한 가설:
> - View Position: AP는 누워서·이동형 장비로 찍는 중환자 영상이 많다(화질 저하, 심장 확대 왜곡, 의료기기). AP 비율과 나이·동반 질환 수가 함께 다르므로 단일 원인으로 단정하지 않는다.
> - 연령대: 젊은 층은 유병률이 낮아 양성 수가 적고(CI 넓음), 고령층은 여러 질환이 겹쳐 판별이 어렵다.
> - 성별: 유방 음영, 체형 차이. 학습 데이터 성비(남성 약 56%)도 확인.
